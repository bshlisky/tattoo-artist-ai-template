## 🐛 Reporting Bugs

### Before Submitting

1. Check if the bug has already been reported
2. Make sure you're using the latest version
3. Test in a clean environment

### How to Report

Open an issue on GitHub with:

- **Clear title**: Describe the bug briefly
- **Steps to reproduce**: How can we see the bug?
- **Expected behavior**: What should happen?
- **Actual behavior**: What actually happens?
- **Screenshots**: If applicable
- **Environment**: OS, Node version, browser

**Example**:
```
Title: Logo not displaying on mobile Safari

Steps to reproduce:
1. Add logo to public/ folder
2. Update ChatWindow.tsx
3. View on iPhone Safari

Expected: Logo displays
Actual: Broken image icon shows

Environment: iOS 17, Safari, Node 20.x
```

## 💡 Suggesting Features

We love new ideas! Before suggesting:

1. Check if it's already been suggested
2. Consider if it benefits most artists
3. Think about implementation complexity

### How to Suggest

Open an issue with:

- **Feature description**: What do you want?
- **Use case**: Why is this useful?
- **Examples**: How would it work?
- **Alternatives**: Other ways to solve this?

## 🔧 Submitting Code

### Getting Started

1. **Fork the repository**
2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/tattoo-artist-ai-template.git
   ```
3. **Create a branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

### Development Guidelines

#### Code Style

- Use TypeScript for type safety
- Follow existing code formatting
- Use meaningful variable names
- Add comments for complex logic

#### Testing

- Test your changes locally
- Test on mobile devices
- Verify with different themes
- Check API integrations work

#### Commits

Use clear commit messages:

```bash
# Good
git commit -m "Add dark mode toggle to theme system"
git commit -m "Fix logo display issue on mobile Safari"

# Bad
git commit -m "updates"
git commit -m "fix stuff"
```

### Submitting a Pull Request

1. **Push your branch**:
   ```bash
   git push origin feature/your-feature-name
   ```

2. **Open a Pull Request** on GitHub

3. **Describe your changes**:
   - What does this PR do?
   - Why is this change needed?
   - How did you test it?
   - Screenshots (if UI changes)

4. **Wait for review**

## 🎨 Sharing Your Theme

Created a beautiful custom theme? Share it!

### How to Share

1. **Create a theme file**: `app/themes/yourtheme.ts`
2. **Document it**: Add description and screenshots
3. **Submit PR** or share in Discussions

### Theme Guidelines

- Use clear, descriptive names
- Include color palette documentation
- Provide example screenshots
- Test on multiple devices
